# MediaShelf

책(EPUB · PDF · TXT), 만화(CBZ · ZIP · CBR · RAR · 7Z), 그림, 영상을 한 곳에서 관리하고 읽는 개인 라이브러리 앱.
**Windows 를 먼저** 완성하고, 같은 코드로 Android → iOS/macOS 순서로 넓힌다. (Flutter)

## 받기
GitHub Actions 가 push 할 때마다 빌드한다. 저장소의 **Actions → 최신 실행 → Artifacts** 에서
`MediaShelf-windows` (설치파일 `…-windows-setup.exe` + 포터블 zip) 를 받는다.
Android APK 는 태그(`v*`)를 올리거나 Actions 에서 수동 실행할 때 빌드된다.

## 주요 기능

### 라이브러리 (PC 화면)
- 위: 작업 줄 — 폴더 추가 · 파일 추가 · 선택 삭제 · 전체 선택 · 묶기 · 다른 묶음으로 · 숨기기 · 사용자 접근 · 메타데이터 관리 · 파일 도구 · 공유 서버 · 시리즈 자동 묶기
- 왼쪽: 모아보기(홈 · 즐겨찾기 · 최근 읽음 · 읽는 중 · 다 읽음 · 최근 추가됨 · 누락 권수), 라이브러리 폴더(그룹 · 별칭 · 폴더/파일 수), 종류, 맨 위 묶음, 태그
- 가운데: 검색 · 정렬 · 하위 묶음 포함, 경로 막대(뒤로 · 앞으로 · 위로), 격자 / 표 / 카드 목록
- 아래: 상세 패널(표지 · 읽기 · 태그 · 정보 표 · 줄거리 · 10점 별점), 상태 막대(선택 · 개수 · 용량 · 보기 방식 · 항목 크기)
- 한 번 클릭 = 고르기, 더블클릭 = 열기, Ctrl+클릭 = 여러 개, 오른쪽 클릭 = 메뉴
- 홈: 넷플릭스풍 큰 배너 + 가로 줄(보던 작품 · 최근 추가 · 종류별 · 즐겨찾기)

### 시리즈(묶음)
- 몇 단계든 중첩: 명탐정 코난 › 본편 / 외전 / 극장판
- 파일명으로 자동 묶기 ("01권", "제3권", "v05", "S02E03", "10.5권" …), 파생 시리즈는 대표 묶음 아래로
- 보유 / 전체 권수, 연재중 · 완결 · 휴재, 누락 권수 확인, 다음에 읽을 권

### 뷰어
- **만화**: 위 도구줄, 가로/높이/전체/원본 맞춤, 확대, 한장/두장/스크롤(웹툰), 커버 단독/포함, 읽기방향, 몰입형 배경, 넘김효과(슬라이드 · 페이드 · 책 넘김), 썸네일 줄, 책갈피, 전체화면
- **TXT · EPUB**: 목차 / 하이라이트 / 본문 검색 패널, 테마 7종, 글꼴, 글자 크기 · 줄 간격 · 본문 폭, 글자 선택 → 색칠 · 복사 · 검색 · AI 뜻풀이, 장 탐색 줄, **소리 내어 읽기(TTS)** — 대사/속마음 다른 음성
- **PDF**: 같은 도구줄, 썸네일 줄, 책갈피
- **그림**: 넘기기, 확대, 슬라이드쇼 / **영상**: 이어보기, 배속, A-B 구간 반복, 다음 화 자동 재생
- 읽던 위치 · 열람 기록은 사용자마다 따로 저장

### 메타데이터
- 통합검색 창: 카카오 · 네이버 · Google Books · Open Library 동시 검색, 결과 목록 + 상세, 적용할 항목 고르기, AI 원제 찾기
- 일괄 편집기: 원본 / 일괄 두 칸, 시리즈 자동 매칭, 자동 제목 · 권수 · 페이지 수, 모두 저장

### 파일 도구
- 압축 파일 구조 정리(평탄화), 내부 파일명 변경(번호 · 순서 · 빼기), 표지 추가 및 교체(이미지 파일 · 인터넷 검색 · 책 내부 이미지), 텍본 정리기(UTF-8 변환), 원본 .bak 백업

### 공유 서버
- 같은 Wi-Fi 에서 브라우저로 둘러보기 · 내려받기, OPDS(Panels · ComicGlass · KyBook), 아이디/비밀번호, 숨김 항목 제외, 접속 로그

### 사용자 · 보안
- 첫 실행 시 관리자 계정, "누가 보고 있나요?" 프로필 선택
- 관리자: 사용자 추가/삭제, 사용자별 접근 권한(묶음 단위)
- 숨김: 숨김 비밀번호를 검색창에 입력하면 드러남, 앱을 닫으면 다시 숨김, Windows 파일 숨김 속성도 함께
- 모든 삭제는 "목록에서만 / 원본 파일까지" 확인

### 환경 설정
- 일반 · 라이브러리(폴더 · 그룹 · 별칭 · 순서) · 파일 처리 · 뷰어 · 검색 API · AI 도우미 · 계정 · 정보

## 개발
```bash
flutter create --platforms=windows,android --org com.mediashelf --project-name media_shelf .
flutter pub get
flutter run -d windows
```
플랫폼 폴더는 CI 에서 `flutter create` 로 만들고 `tool/patch_windows.py`, `tool/patch_android.py` 로 다듬는다.
