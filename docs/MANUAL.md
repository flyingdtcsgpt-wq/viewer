# ARARIFlex 사용 설명서

책 · 만화 · 그림 · 영상을 한 곳에서 정리하고 보는 앱입니다. (버전 0.5.0)

---

## 1. 설치

### Windows
1. https://github.com/flyingdtcsgpt-wq/viewer/actions 에서 맨 위(초록 ✔) 실행을 누릅니다.
2. 아래쪽 **Artifacts** 의 `ARARIFlex-windows` 를 받아 압축을 풉니다.
3. `ARARIFlex-0.5.0-windows-setup.exe` 를 실행합니다. (설치 없이 쓰려면 `…-portable.zip`)
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** (서명 인증서가 없어서 뜨는 안내입니다)
- 인터넷 없는 PC 에서도 됩니다. 영상 코덱 · 자막 · 압축(RAR/7Z) 도구가 모두 들어 있습니다.

### Android
- Actions 의 Artifacts 에서 `ARARIFlex-android` 를 받아 `ARARIFlex-…-android.apk`(요즘 폰, 약 88MB) 를 설치합니다.
  아주 오래된 32비트 폰은 `…-android-old32bit.apk`.
- 처음 폴더를 추가할 때 **모든 파일 접근 허용**을 켜야 폴더 안 파일을 읽을 수 있습니다.
- 파일 관리자에서 책 · 만화 파일을 누르고 **ARARIFlex 로 열기**를 고르면 바로 열리고 라이브러리에도 들어갑니다.
- 폰에서는 RAR · 7Z 만화를 아직 열 수 없습니다(ZIP · CBZ 는 됨). PC 버전에서 보세요.
- 소리 내어 읽기: 폰에 들어 있는 음성(기기 음성)과 자연스러운 음성(설정에서 받기) 모두 쓸 수 있습니다.
  뷰어 제목 줄 오른쪽의 🔊 버튼, 또는 목록에서 길게 눌러 **소리 내어 읽기로 열기**.
- 그림 · PDF · 만화의 글자 인식은 폰 안에서 처리됩니다(Google ML Kit 한국어, 인터넷 불필요).

### 태블릿 (안드로이드 태블릿 · 아이패드)
- 휴대폰과 같은 앱입니다. 가로로 두면 PC 처럼 왼쪽 메뉴 · 위 작업 줄이 보이고, 세로로 두면 휴대폰처럼 아래 탭이 보입니다.

### macOS (맥북 · 아이맥) — macOS 14 Sonoma 이상
1. Actions 의 Artifacts 에서 `ARARIFlex-macos` 를 받아 `ARARIFlex-…-macos.dmg` 를 엽니다.
2. ARARIFlex 를 응용 프로그램 폴더로 끌어 넣습니다.
3. 처음 열 때 "확인되지 않은 개발자" 경고가 나오면: Finder 에서 **ARARIFlex 를 Control+클릭 → 열기 → 열기**
   (또는 시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기"). 한 번만 하면 됩니다.
- 글자 인식은 macOS 내장 Vision(한국어), 기기 음성은 macOS 음성을 씁니다. 자연스러운 음성도 그대로 됩니다.

### iPhone · iPad — iOS 16 이상
애플 정책상 앱스토어 밖 설치는 본인 Apple ID 로 서명해야 합니다.
1. Actions 의 Artifacts 에서 `ARARIFlex-ios` 를 받아 `ARARIFlex-…-ios-unsigned.ipa` 를 PC/맥에 둡니다.
2. **Sideloadly**(윈도우 · 맥) 또는 **AltStore** 로 그 .ipa 를 아이폰에 설치합니다 (Apple ID 로그인 필요).
3. 아이폰 설정 → 일반 → VPN 및 기기 관리 → 내 Apple ID → **신뢰**. 설정 → 개인정보 보호 및 보안 → **개발자 모드** 켜기(iOS 16+).
- 무료 Apple ID 는 7일마다 다시 설치(Sideloadly/AltStore 가 갱신)해야 합니다. 유료 개발자 계정(연 129,000원)이면 1년.
- **책 넣기**: 아이폰은 다른 앱의 폴더를 계속 읽을 수 없어서, **파일 앱 › 나의 iPhone › ARARIFlex** 폴더가 라이브러리입니다.
  여기에 책 · 만화 · 그림 · 영상(폴더째도 됨)을 넣으면 앱을 켤 때 · 돌아올 때 자동으로 들어옵니다.
  "파일 추가"로 고른 파일은 이 폴더로 복사됩니다. 맥 Finder / 윈도우 Apple 기기 앱의 파일 공유로도 넣을 수 있습니다.
- RAR · 7Z 만화는 아직 PC · 맥에서만 열립니다.

## 2. 처음 시작
1. 처음 켜면 **관리자 계정**(이름 · 비밀번호)을 만듭니다.
2. 다음부터는 "누가 보고 있나요?" 에서 프로필을 고르고 비밀번호를 넣습니다.
3. 관리자는 **관리자 메뉴(👤⚙ 아이콘)** 에서 가족 계정을 더 만들 수 있습니다.

## 3. 작품 넣기
위쪽 빨간 **＋ 추가** → **폴더 추가** · **파일 추가** · **NAS · WebDAV 에서 가져오기**

**NAS · WebDAV 에서 가져오기**: 시놀로지(예: `https://NAS주소:5006/폴더`) · 큐냅 · 아이피타임 NAS, WebDAV 를 지원하는 클라우드,
다른 PC 의 ARARIFlex 공유 서버(`/dav/`)에 접속해 폴더를 둘러보고, 파일이나 폴더째 골라 이 기기로 받은 뒤 아래 가져오기 창으로 넣습니다.
받은 파일은 서버 폴더 구조 그대로 둡니다(라이브러리 폴더를 정해 두었으면 그 안 `NAS/서버이름`). 서버 주소와 아이디는 저장되고 비밀번호는 저장하지 않습니다.
PC 에서는 NAS 공유 폴더(SMB)를 네트워크 드라이브로 연결한 뒤 그 폴더를 **폴더 추가** 해도 됩니다(파일을 받지 않고 바로 읽음).

폴더를 고르면 찾은 파일 목록이 나옵니다.
- ☑ 체크한 것만 들어갑니다. **전체 선택/해제**, **새 항목만 선택**
- 위쪽 칩(책 · 만화 · 그림 · 영상)과 "경로로 찾기"로 목록을 거를 수 있습니다. **보이는 것 중 체크한 것만** 추가됩니다.
- 상태 표시
  - `새 항목` 처음 보는 파일
  - `중복 의심` 이미 있는 파일과 내용이 같아 보임 (기본으로 체크 해제)
  - `등록됨` 이미 라이브러리에 있음
- **추가 방식**
  - 원본 위치에 연결: 파일은 그대로, 목록에만 넣음 (기본)
  - 라이브러리 폴더로 복사: 정리 폴더에 사본을 만듦
  - 라이브러리 폴더로 이동: 정리 폴더로 옮김 (원래 자리에서 사라짐)
- **묶기**
  - 파일명으로 시리즈 자동 묶기 ("01권", "S01E02" …)
  - 폴더 구조 그대로 묶음 만들기
  - **폴더 전체를 묶음 하나로**: 잡동사니 폴더를 표지 하나로 묶고, 카드에 책 · 그림 · 영상 개수를 따로 표시
  - 묶지 않음
- **숨김으로 추가**: 처음부터 숨긴 상태로 (관리자 + 숨김 비밀번호가 있어야 함)
- **라이브러리 폴더로 등록**: 왼쪽에 폴더가 보이고 F5(다시 스캔) 때 새 파일을 찾습니다.
- 이미 등록한 폴더 **안쪽** 폴더를 고르면 알려 주고 새 파일만 보여 줍니다. **바깥쪽** 폴더를 등록하면 안쪽 폴더들이 하나로 합쳐집니다.

## 4. 둘러보기 (PC)
- 왼쪽: 홈 · 즐겨찾기 · 최근 읽음 · 읽는 중 · 다 읽음 · 최근 추가 · 누락 권수 · 라이브러리 폴더 · 종류 · 묶음 · 태그
- 가운데: 검색 · 정렬 · 하위 묶음 포함, 격자 / 표 / 카드 보기, 아래 막대에서 **항목 크기** 조절
- 한 번 클릭 = 고르기, 더블클릭 = 열기, Ctrl+클릭 = 여러 개, 오른쪽 클릭 = 메뉴
- 고르면 위 작업 줄에 **삭제 · 묶기 · 다른 묶음으로 · 메타데이터 · 숨기기 · 사용자 접근** 이 나타납니다.
- **…(더보기)**: 전체 선택(Ctrl+A), 시리즈 자동 묶기, 파일 도구, 공유 서버
- 단축키: Enter 열기, Del 삭제, Esc 선택 해제/위로, Alt+← → 뒤로/앞으로, F5 다시 스캔
- 삭제할 때는 항상 **목록에서만 / 원본 파일까지** 를 묻습니다.

휴대폰에서는 아래 탭(홈 · 책 · 만화 · 그림 · 영상)과 왼쪽 위 ☰ 메뉴를 씁니다.

### 보던 목록에서 빼기
홈의 "보던 작품" 과 왼쪽 "읽는 중" 에는 조금이라도 연 작품이 나옵니다. 빼고 싶으면:
- 홈 "보던 작품" 카드 왼쪽 위 **×**, 또는 목록에서 오른쪽 클릭(휴대폰은 길게 누르기) → **보던 목록에서 빼기** (여러 개 골라서도 됨), 또는 상세 화면의 단추
- 읽은 위치는 지워지지 않습니다. **나중에 다시 열어 읽으면 저절로 다시 나옵니다.** 바로 뒤 "되돌리기" 로 취소할 수 있습니다. 계정마다 따로 기억합니다.

## 6. 소리 내어 읽기
### 자연스러운 음성 받기 (처음 한 번)
**설정 → 읽어주기 음성 → 인터넷에서 받기** (약 380MB, 무료 · 이후 오프라인)
- 인터넷 없는 PC: 다른 PC 에서 https://huggingface.co/supertone-oss-archive/supertonic-3 의
  `onnx` 폴더와 `voice_styles` 폴더를 받아 USB 로 옮긴 뒤 **폴더에서 가져오기**
- 같은 화면에서 **들어 보기**, **기본 음성으로** 지정
- 목소리: 자연 음성 · 여성 1~5, 남성 1~5 (+ Windows 기본 음성)

### TXT · EPUB
도구줄 **TTS** (휴대폰은 제목 줄의 🔊) → ▶. 목록에서 오른쪽 클릭/길게 눌러 **소리 내어 읽기로 열기** 로 바로 시작할 수도 있습니다.
- 속도, 기본 음성
- ☑ "큰따옴표=대사, 작은따옴표=속마음" 을 켜면 대사 · 속마음 목소리를 따로 고를 수 있습니다.
- **인물별 목소리**: 책에서 "○○가 말했다" · "said Holmes" 같은 문장을 보고 말하는 인물을 찾아 줍니다(말한 횟수 순).
  인물마다 목소리를 고르고 저장(책마다 따로). 찾지 못한 인물은 이름을 직접 추가할 수 있습니다.
  - **자동 배역**(기본 켜짐): 목소리를 고르지 않은 인물도 자연 음성(영어 책은 Kokoro) 중 서로 다른 목소리를 남녀 번갈아 붙이고,
    책 끝까지 같은 목소리로 읽습니다. **자동 배역 고정** 을 누르면 붙은 목소리가 저장되어 하나씩 바꾸기 쉽습니다.
  - **주고받는 대사**(기본 켜짐): 화자가 안 적힌 대사가 대사만으로 이어지면 앞의 두 사람이 번갈아 말한 것으로 봅니다.
    중간에 서술이 끼면 확신이 없어 "대사" 목소리로 읽습니다.
  - 영어 원서: Mr./Dr./St. 같은 약어를 풀어 읽고("Mister", "Saint/Street"), 영국식처럼 작은따옴표가 대사인 책은 알아서 대사로 봅니다.
  - 목소리가 바뀔 때(서술 ↔ 대사 ↔ 다른 인물) 짧게 쉬어 덜 급하게 들립니다.
  - **AI 로 화자 분석**(선택): 인물별 목소리 창의 단추. 규칙으로 못 찾은 대사를 Claude API 가 앞뒤 흐름을 보고 찾아 줍니다
    (설정 › AI 도우미에 키 필요, 책 한 권에 보통 수백 원 안팎). 결과는 책마다 이 기기에 저장되고, 멈췄다가 이어서 할 수 있습니다.
    기기 안 AI 모델은 쓸 만한 정확도면 1GB 가 넘고 책 한 권에 몇 시간 걸려 넣지 않았습니다.
- **배경음** ♪: 빗소리 · 파도 · 벽난로 · 갈색/분홍/백색 소음(앱이 직접 만든 소리) 또는 내 소리 파일. 볼륨 막대로 조절,
  읽기를 멈추거나 취침 타이머가 끝나면 함께 꺼집니다.
- 영어 책을 열면 "Kokoro 영어 성우로 읽기" 단추가 나옵니다(Kokoro 를 받아 둔 경우).

### 소설 PDF
소리 내어 읽기는 **소설(TXT · EPUB · PDF)** 용입니다. 만화 · 그림은 읽지 않습니다.
PDF 도구줄 🔊 → ▶ 이 쪽부터 읽기, 끝나면 다음 쪽으로 넘어가며 계속 읽습니다.
- 글자가 들어 있는 PDF 는 그대로 읽고, 스캔한 PDF 는 **글자 인식(OCR)** 으로 읽습니다.
- Windows 에서는 설정 › 읽어주기 · 글자 인식 › **한국어 글자 인식 모델(PaddleOCR)** 을 받아 두세요(약 20MB).
  Windows 언어 설정과 상관없이 한국어를 정확히 읽습니다. 안드로이드 · 맥 · 아이폰은 기기에 들어 있는 인식기를 씁니다.

### 취침 타이머 · 화면 꺼도 계속 읽기
- 읽어주기 막대의 🌙: 15 · 30 · 45분 · 1시간 · 1시간 30분 뒤, 또는 **이 장이 끝나면** 멈춥니다.
- 안드로이드: 읽는 동안 알림("소리 내어 읽는 중")이 떠 있고, 화면을 꺼도 계속 읽습니다. 멈추면 알림도 사라집니다.

### 오디오북으로 저장 (소리 파일 만들기)
TXT · EPUB 읽어주기 막대 → **오디오북으로 저장 (장마다 소리 파일)**
- 지금 고른 음성 그대로 만듭니다 (대사 · 속마음 · 인물별 목소리 포함). 인터넷 없이 이 기기에서 만듭니다.
- 범위: 책 전체 / 지금 장부터 / 지금 장만. 차례가 없는 TXT 는 약 2만 자(20~30분)씩 나눕니다.
- 형식: **M4A**(작음, 권장 · 아이폰 · 안드로이드 · PC 음악 앱 모두 재생) 또는 **WAV**(원음, 약 4배 큼).
  **장마다 파일** 또는 **한 파일로 합치기**(책 전체가 파일 하나)
- 저장 위치: PC 는 `음악\ARARIFlex 오디오북\책 제목`, 안드로이드는 `Audiobooks` 폴더(파일 권한이 없으면 앱 폴더),
  아이폰 · 아이패드는 **파일 앱 › 나의 iPhone › ARARIFlex**. 파일 이름은 `001 제1장 ….m4a` 처럼 차례 번호가 붙고,
  차례대로 듣는 목록(`책 제목.m3u8`)도 함께 만듭니다.
- 긴 책은 오래 걸립니다(자연 음성은 PC 에서 대략 듣는 시간의 1/5~1/2). 진행 창에서 **멈춤** 을 누르면 다 만든 장은 남고,
  다시 만들면 **이어서** 만듭니다. 안드로이드는 화면을 꺼도 계속 만듭니다.
- M4A 로 줄이지 못하는 PC(Windows N 판 등 Media Foundation 이 없는 경우)는 WAV 로 저장하고 알려 줍니다.

### 영어 원서 (선택)
설정 › 읽어주기 · 글자 인식 › **영어 원서용 AI 성우 (Kokoro)** → 받기(약 340MB, PC 전용).
그 뒤 읽어주기 막대의 음성 목록에서 "Kokoro 영어(미국/영국) 남성 · 여성 …"(28가지)을 고릅니다.
한국어 문장이 섞여 나오면 한국어 자연 음성으로 바꿔 읽습니다.

## 7. 메타데이터
- 항목 상세 → ✎ 또는 **메타데이터** 버튼: 카카오 · 네이버 · Google Books · Open Library 를 한 번에 검색해 고른 항목만 적용
- 여러 권을 골라 **일괄 편집**: 시리즈 자동 매칭, 제목 · 권수 · 쪽수 자동
- 검색 API 키는 설정 → 메타데이터 검색 및 API

## 8. 숨김
1. 관리자 메뉴에서 **숨김 비밀번호**를 정합니다.
2. 숨길 항목/묶음을 고르고 **숨기기** (또는 폴더 추가 때 "숨김으로 추가")
   - 전체를 숨기려면 라이브러리 폴더째 숨김으로 추가, 일부만 숨기려면 골라서 숨기기
3. 숨긴 것을 볼 때: **검색창에 숨김 비밀번호를 입력** → 드러남. 위쪽 "잠그기" 또는 앱을 닫으면 다시 숨겨집니다.
- Windows 파일 숨김 속성도 같이 바뀝니다. 공유 서버에는 숨긴 것이 나오지 않습니다.

## 9. 계정별로 보여 줄 범위 (관리자)
관리자 메뉴 → 사용자 → **접근 권한**
- **라이브러리 폴더**: 끄면 그 폴더 안 모든 파일이 안 보임
- **종류**: 예) 아이 계정에서 영상만 막기 (탭에서도 사라짐)
- **묶음 · 작품**: 묶음을 끄면 그 안 전부가 막힘
막힌 것은 목록 · 홈 · 검색 · 열람 기록 · 공유 서버 어디에도 나오지 않습니다.

## 10. 공유 서버 (같은 Wi-Fi)
…(더보기) → **공유 서버**
- 아이디 · 비밀번호를 정하고 켜기 → 휴대폰/태블릿 브라우저에서 `http://PC주소:포트` 로 접속
- OPDS 앱(Panels, ComicGlass, KyBook): `http://PC주소:포트/opds`
- **앱 계정 이름과 비밀번호로 로그인하면 그 계정의 권한이 그대로** 적용됩니다.
- 공용 아이디로 볼 수 있는 범위는 "이 아이디로 볼 수 있는 범위" 에서 계정을 골라 정합니다.
- **QR 코드**: 서버를 켜면 웹 · WebDAV 주소가 QR 로 나옵니다. 휴대폰 카메라로 찍으면 바로 열립니다.
- **WebDAV**: `http(s)://PC주소:포트/dav/` — 파일 관리자(Solid Explorer, CX 파일 탐색기), 리더 앱(KOReader, Documents),
  다른 기기의 ARARIFlex("NAS · WebDAV 에서 가져오기")에서 묶음이 폴더로 보입니다. 읽기 전용, 이어받기 지원.
- **HTTPS(암호화)**: 켜면 같은 Wi-Fi 의 다른 사람이 비밀번호 · 파일을 엿볼 수 없습니다. 이 PC 가 만든 인증서라 처음 접속할 때
  브라우저 경고가 뜨면 "고급 › 계속" 을 누르세요(화면에 나오는 인증서 지문과 같은지 볼 수 있음). ARARIFlex 끼리는 "인증서 확인 안 함" 을 켜고 연결합니다.

## 11. 파일 도구
…(더보기) → **파일 도구**. 목록에서 먼저 고르면 고른 것만, 아니면 지금 보이는 목록이 대상입니다.
| 도구 | 하는 일 |
|---|---|
| 텍본 정리기 · 인코딩 변환 | CP949 → UTF-8, 줄 끝 공백 · 빈 줄 정리 |
| TXT → EPUB | "제1장" 같은 줄로 자동 목차, 표지 넣기 |
| **PDF → 텍스트** | PDF 의 글을 TXT · EPUB 으로. 스캔한 PDF 는 글자 인식으로 읽고, 쪽 번호 · 되풀이되는 머리글은 빼고 끊긴 문장은 잇습니다. 만든 책은 소리 내어 읽기 · 오디오북 저장을 쓸 수 있습니다 |
| **이미지 → PDF** | 만화 한 권(CBZ · ZIP · CBR · 7Z) → PDF 하나, 고른 그림 여러 장 → PDF 하나 (JPEG 는 화질 그대로) |
| **PDF 나누기 · 합치기** | N쪽마다 / 쪽 범위(`1-10, 11-`)로 나누기, 여러 PDF 를 끌어서 순서를 정해 하나로 |
| 압축 파일 구조 정리 · 내부 파일명 변경 · 표지 | 폴더 없애기, 000 · 001 번호, 표지 추가 · 교체(자르기 · 회전 · 밝기) |
| **이미지 해상도 변경** | 만화 속 그림 · 그림 파일을 긴 변 1200~2560px 로 줄여 용량 절약 (PNG → JPEG 선택) |
| **EPUB 용량 최적화** | 안의 큰 삽화를 줄이고 글을 다시 압축 (본문은 그대로) |
| 메타데이터 관리 | 여러 권 정보 한 번에 |

원본을 바꾸는 도구는 바꾸기 전 원본을 `.bak` 으로 남길 수 있습니다(기본 켜짐). 새 파일을 만드는 도구는 원본을 건드리지 않습니다.

## 12. 휴대용 모드 (USB 로 다른 PC 에 옮기기)
- **포터블 zip** 을 풀면 `ARARIFlex` 폴더 안에 `arariflex_data` 폴더가 있습니다. 이 폴더가 있으면 라이브러리 · 설정 · 표지 ·
  자연 음성 · 글자 인식 · 영어 성우 모델이 **모두 그 안에** 저장됩니다.
- 인터넷 되는 PC 에서 필요한 모델을 한 번 받은 뒤, `ARARIFlex` 폴더를 **통째로 USB 에 복사**해 인터넷 없는 PC 에서 그대로 실행하면 됩니다.
- 지금 쓰던 데이터를 휴대용으로 옮기려면: 설정 › 정보 › 휴대용 모드 › **지금 데이터를 옮겨 휴대용으로 만들기** → 앱 다시 켜기.
  (설치판은 Program Files 에 있어서 휴대용으로 만들 수 없습니다. 포터블 zip 을 쓰세요.)
- `arariflex_data` 폴더를 지우면 일반 모드(%APPDATA%)로 돌아갑니다. 맥은 ARARIFlex.app 옆에 같은 이름의 폴더를 만들면 됩니다.

## 13. 비밀번호를 잊었을 때
- **숨김 비밀번호**: 관리자 메뉴에서 언제든 새로 정할 수 있습니다.
- **관리자 비밀번호**:
  1. 앱을 끕니다.
  2. 데이터 폴더(관리자 메뉴 · 설정 → 정보에 경로 표시, Windows 는 보통 `%APPDATA%\com.mediashelf\media_shelf`)에
     **`RESET_PASSWORD.txt`** 라는 빈 파일을 만듭니다.
  3. 앱을 켜면 초기화 화면이 나옵니다. 새 비밀번호를 두 번 넣고, 필요하면 "숨김 비밀번호도 지우기".
  4. 끝나면 파일은 자동으로 지워집니다.

## 14. 자주 묻는 것
- **폴더를 추가했는데 아무것도 안 보여요 (Android)**: 설정에서 ARARIFlex 의 "모든 파일 접근" 을 허용하세요.
- **RAR/7Z 만화가 안 열려요**: 설치판에는 7-Zip 이 들어 있습니다. 포터블판은 `tools\7zip` 폴더가 같이 있어야 합니다.
- **소리 내어 읽기가 기계 같아요**: 6장의 자연스러운 음성을 받으세요.
- **설정은 어디에 저장되나요**: 데이터 폴더(12장)에 `library.db`, 표지 캐시, 음성 모델이 있습니다. 이 폴더를 백업하면 됩니다.
