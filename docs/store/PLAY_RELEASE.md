# 플레이스토어판 출시 안내

전체판(PC · 안드로이드 직접 설치)은 그대로 두고, Google Play 에는 기능을 줄이고 광고를 붙인 **플레이스토어판**을 따로 올립니다. 코드는 하나이고 빌드할 때 `--dart-define=ARARI_STORE=true` 를 붙이면 플레이스토어판이 됩니다 (`lib/edition.dart`).

| | 전체판 | 플레이스토어판 |
|---|---|---|
| 패키지 | `com.mediashelf.media_shelf` | `com.arariflex.app` |
| 보는 것 | 만화 · 책 · 영상 · 그림 | 만화 · 책 · 영상 |
| 서재 위치 | 아무 폴더나 등록 (모든 파일 접근 권한) | 앱 전용 `ARARIFlex` 폴더 하나 (권한 없음) |
| 넣는 방법 | 폴더 등록 | 가져오기(파일 · 폴더 고르기, 복사/옮기기) · 공유 · PC 에서 USB |
| AI · NAS(WebDAV) · 공유 서버 · 읽어주기 · 글자 인식 · 파일 도구 · 계정 · 숨김 · 백업 | 있음 | 없음 |
| 광고 | 없음 | 목록 아래 배너 + 앱을 켤 때 (아래 규칙) |
| 빌드 | CI `android` 작업 (APK) | CI `store` 작업 (AAB + 시험용 APK) |

## 광고 규칙 (거슬리지 않게)

- **배너**: 목록 화면 맨 아래 한 줄 (적응형 배너). 서재가 비어 있을 때 · 만화/책/영상을 보는 중에는 없음. 아래 탭과 붙어 잘못 누르지 않게 띄워 둠.
- **앱 열기 광고**: 앱을 켤 때 잠깐. 설치한 첫날은 없음, **4시간에 한 번까지**, 켠 뒤 5초 안에 준비되지 않으면 그 번은 건너뜀(쓰는 중에 끼어들지 않게). 1시간 넘게 쉬었다 돌아올 때도 같은 규칙.
- **앱을 끌 때 광고는 넣지 않음**: AdMob 정책상 앱을 나가는 동작(뒤로 가기로 종료 등)에 전면 광고를 띄우는 것은 금지입니다.
- 유럽 · 영국 등은 처음에 Google 동의 창(UMP)이 뜨고, 동의 없이는 광고를 요청하지 않음. 설정 › 정보 › "광고 개인정보 선택"으로 다시 고를 수 있음.

## 1. 한 번만 하는 준비

1. **Play Console 개발자 계정** (25달러, 신원 확인). 2023-11 이후 만든 개인 계정은 **비공개 테스트에 테스터 12명 이상이 14일 연속 참여**해야 프로덕션 출시를 신청할 수 있습니다.
2. **AdMob 계정** (https://admob.google.com) → 앱 추가(안드로이드, 아직 스토어에 없음으로 시작) → 광고 단위 2개 만들기: `배너`, `앱 오픈`. 받은 값 3개를 GitHub 저장소 **Settings › Secrets and variables › Actions** 에 등록:
   - `ADMOB_APP_ID` = `ca-app-pub-XXXXXXXX~YYYYYYYY` (앱 ID, `~` 들어간 것)
   - `ADMOB_BANNER_ID` = `ca-app-pub-XXXXXXXX/ZZZZZZ` (배너 광고 단위)
   - `ADMOB_APP_OPEN_ID` = `ca-app-pub-XXXXXXXX/WWWWWW` (앱 오픈 광고 단위)
   - 등록하지 않으면 Google **시험 광고**가 나옵니다(출시용으로는 꼭 등록). 개발 중 본인이 실제 광고를 누르면 AdMob 계정이 정지될 수 있으니, 시험할 때는 AdMob › 설정 › 테스트 기기에 본인 폰을 넣어 두세요.
3. AdMob › 개인정보 보호 및 메시지 › **GDPR · 미국 주 규정 메시지** 만들기 (동의 창 문구). 만들지 않으면 유럽에서 광고가 나오지 않습니다.
4. **app-ads.txt**: AdMob 이 안내하는 한 줄을 개발자 웹사이트 최상위(`https://내도메인/app-ads.txt`)에 올리고, 같은 사이트 주소를 Play 등록정보의 웹사이트에 적습니다. (없어도 광고는 나오지만 수익이 줄 수 있음. GitHub Pages 로도 가능)
5. 서명: 직접 설치판과 같은 키(이미 등록한 `ANDROID_KEYSTORE_*` Secrets)를 **업로드 키**로 씁니다. 첫 업로드 때 Play 앱 서명(Google 이 최종 서명 관리)에 동의하세요.

## 2. 빌드

push 할 때마다 CI `store` 작업이 만듭니다. Artifact **ARARIFlex-store** 안에:

- `ARARIFlex-store-<판>.aab` → Play Console 에 올리는 파일
- `ARARIFlex-store-<판>-test.apk` → 폰에 직접 깔아 보는 시험용 (직접 설치판과 패키지가 달라 둘 다 깔림)
- `store-check.txt` → targetSdk · 권한 목록 · 16KB 페이지 정렬 검사 결과

버전 코드는 CI 실행 번호 + 1000 이라 올릴 때마다 자동으로 커집니다. 버전 이름은 `pubspec.yaml` 의 `version`.

## 3. Play Console 에 적을 것

### 앱 만들기
- 앱 이름: **ARARIFlex - 만화 · 책 · 영상 뷰어** (30자 이내)
- 기본 언어: 한국어 · 앱 · 무료 · **광고 포함: 예**

### 스토어 등록정보
- 간단한 설명 (80자):
  > 내 만화(CBZ·ZIP)·책(EPUB·PDF·TXT)·영상을 한곳에. 시리즈 자동 정리, 이어 보기.
- 자세한 설명:
  > ARARIFlex 는 내 기기에 있는 만화 · 책 · 영상을 깔끔하게 모아 보는 뷰어입니다.
  >
  > • 만화: CBZ · ZIP. 한 쪽/두 쪽 보기, 오른쪽→왼쪽 넘김, 세로 스크롤(웹툰)
  > • 책: EPUB · PDF · TXT. 글꼴 · 크기 · 줄 간격 · 배경색, 페이지/스크롤 보기
  > • 영상: MP4 · MKV 등. 이어 보기, 자막
  > • 1권 · 2권… 시리즈를 자동으로 묶고, 다 읽으면 다음 권으로 바로 이어 보기
  > • 보던 목록, 다 본 표시, 표지 자동 생성
  > • 회원 가입 없음. 파일과 기록은 기기 안에만 저장됩니다
  >
  > 넣는 방법: 앱의 "가져오기"로 파일이나 폴더를 고르거나, 다른 앱에서 "공유 → ARARIFlex", 또는 PC 에 USB 로 연결해 `Android/data/com.arariflex.app/files/ARARIFlex` 폴더에 넣으세요.
  >
  > ARARIFlex 는 콘텐츠를 제공하거나 내려받지 않습니다. 직접 구입했거나 이용 권한이 있는 파일만 이용해 주세요.
- 그래픽: 앱 아이콘 512×512, 그래픽 이미지 1024×500, 휴대전화 스크린샷 2~8장 (태블릿 있으면 7"/10" 각각)
- **저작권 주의**: 스크린샷 · 그래픽 이미지에 실제 판매 중인 만화 · 책 표지, 영화 장면, 다른 앱 · 서비스의 이름 · 로고를 넣지 마세요(가장 흔한 거절 사유). 직접 만든 표지나 저작권이 끝난 작품(공유마당 · 프로젝트 구텐베르크 등)만 쓰세요. 설명에도 "넷플릭스" 같은 다른 회사 이름을 쓰지 않습니다.
- 카테고리: **도서/참고자료** (또는 만화) · 이메일: 개발자 연락용 이메일 · 웹사이트: app-ads.txt 를 둔 사이트
- 개인정보처리방침 URL: `https://github.com/flyingdtcsgpt-wq/viewer/blob/main/docs/store/PRIVACY.md` (다른 주소에 올리면 빌드 때 `--dart-define=PRIVACY_URL=...` 로 앱 안 링크도 바꿀 것)

### 앱 콘텐츠 (정책 신고)
- **개인정보처리방침**: 위 URL
- **광고**: 예, 광고 포함
- **앱 액세스 권한**: 모든 기능을 제한 없이 이용 가능 (로그인 없음)
- **콘텐츠 등급** (IARC 설문): 폭력 · 성적 콘텐츠 · 욕설 · 약물 · 도박 모두 "아니요". 사용자 간 소통 · 콘텐츠 공유 "아니요", 위치 공유 "아니요", 디지털 구매 "아니요". 앱이 콘텐츠를 제공하지 않는 뷰어라는 점은 설명에 적혀 있으면 충분합니다. → 보통 전체 이용가 / 3+ 로 나옵니다.
- **타겟층**: 만 18세 이상 (또는 13세 이상). **13세 미만 포함하지 말 것** — 포함하면 가족 정책 · 아동용 광고 인증이 필요해집니다.
- **뉴스 앱**: 아니요 · **정부 앱**: 아니요 · **금융 기능**: 없음 · **건강**: 없음
- **광고 ID**: 예, 사용 (용도: 광고 · 마케팅). 매니페스트에 `AD_ID` 권한이 들어갑니다(광고 SDK 가 넣음).
- **데이터 보안** (Data safety):
  - 데이터 수집: **예** (광고 SDK 때문)
  - 수집 항목:
    - 기기 또는 기타 ID → 광고 ID: 수집 · 공유(Google), 용도: 광고 또는 마케팅, 분석, 사기 방지 · 보안
    - 위치 → 대략적인 위치(IP 기반): 수집, 용도: 광고 또는 마케팅
    - 앱 활동 → 앱 상호작용(광고 노출 · 클릭): 수집 · 공유, 용도: 광고 또는 마케팅, 분석
    - 앱 정보 및 성능 → 비정상 종료 로그 · 진단: 수집, 용도: 분석
  - 전송 중 암호화: 예 · 삭제 요청 방법: 앱 삭제(앱 데이터), 광고 ID 는 기기 설정에서 재설정/삭제
  - 넣은 파일 · 읽은 기록은 기기를 떠나지 않으므로 "수집"이 아닙니다(신고 대상 아님).
  - (AdMob 공식 안내: https://developers.google.com/admob/android/privacy/play-data-disclosure — SDK 판에 따라 항목이 바뀌면 이 문서를 따르세요)
- **권한**: 인터넷 · 네트워크 상태 · 광고 ID 뿐. 저장소 · 사진/동영상 · 모든 파일 · 알림 · 포그라운드 서비스 권한 없음 → 별도 권한 신고서 없음.

## 4. 출시 순서

1. Play Console › 테스트 › **비공개 테스트** 트랙 만들기 → 테스터 이메일 목록(12명 이상) → AAB 업로드 → 검토 통과 후 테스터에게 참여 링크 공유
2. 테스터들이 14일 이상 계속 설치해 쓰게 하기 (중간에 버그 고쳐 새 AAB 올려도 됨)
3. 14일이 지나면 **프로덕션 액세스 신청** (테스트 소감 질문에 답) → 승인되면 프로덕션 트랙에 출시
4. 출시 뒤 AdMob 앱 설정에서 "스토어에 등록됨"으로 Play 앱을 연결
