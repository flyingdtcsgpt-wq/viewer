VS Code 와 같은 대화 쓰기

VS Code 에 열려 있는 대화에 휴대폰에서 보내면, 새 Claude 를 띄우지 않고 그 창의 Claude 에게 메시지를 넣습니다. 받는 Claude 에게는 "다른 세션이 보낸 메시지" 로 보여서 민감한 내용에는 조심할 수 있습니다. 내 입력처럼 다루게 하려면 아래 글을 %USERPROFILE%\.claude\CLAUDE.md (맥·리눅스는 ~/.claude/CLAUDE.md) 에 붙여 넣으세요. 이 프로그램이 그 파일을 고치지는 않습니다.
